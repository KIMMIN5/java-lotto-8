# java-lotto-precourse
## 기능 요구 사항
간단한 로또 발매기를 구현한다.
- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
  - Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

---
## User Scenario
1. 사용자는 구매할 로또 수만큼의 금액을 입력한다.
2. 사용자는 구매한 로또들의 번호를 확인한다.
3. 사용자는 당첨 번호를 입력한다.
4. 사용자는 보너스 번호를 입력한다.
5. 사용자는 해당 회차의 당첨 내역 및 수익률을 확인한다.

---
## Main Function
- [ ] 로또를 구매하기 위한 금액을 입력받는다. (1,000원 단위)
- [ ] 랜덤으로 생성된 6개의 숫자를 가진 로또를 금액만큼 생성한다. (1~45 정수, 중복x)
- [ ] 생성된 로또수량, 번호들을 출력한다.(기능 요구 사항 출력양식)
- [ ] 당첨 번호 6개를 입력받는다. (1~45 정수, 중복x)
- [ ] 보너스 번호를 입력받는다. (1~45 정수, 당첨 번호와 중복x)
- [ ] 해당 회차 로또 결과(당첨내역 + 수익률)를 출력한다. (기능 요구 사항 출력양식)

## I/O Rules
- Input
  - 구매 금액: 1,000원 단위, 정수, 그 외 입력(실수, 음수, 1,000원 단위 아님, 공백, 문자)은 예외 처리
  - 당첨 번호: 1~45 사이의 정수, 중복x, 그 외 입력(실수, 음수, 0, 공백, 문자, 중복숫자)은 예외 처리
  - 보너스 번호: 1~45 사이의 정수, 잘못된 입력(실수, 음수, 0, 공백, 문자, 당첨번호와 중복숫자)은 예외 처리
- Output
  - 생성된 로또: 'n개를 구매했습니다.', '[1~45 사이의 정수 6개(쉼표로 구분)]', 숫자는 오름차순으로 정렬
  - 당첨 내역: 각 등수 별로 출력, 양식: 'n개 일치 (각 등수 상금) - n개'
  - 수익률: 소수점 둘 째 자리에서 반올림, 양식: '총 수익률은 n.n%입니다.'
  - 예외 상황: '[ERROR]'로 시작

## Exception Handling
[구매 금액]
- 구매 금액에 공백 입력: [ERROR] 빈 값은 입력할 수 없습니다. 출력 후, 재입력 요청
- 구매 금액에 (실수, 음수, 문자) 입력: [ERROR] 정수 이외의 값은 입력할 수 없습니다. 출력 후 재입력 요청
- 구매 금액에 (1,000원 단위x) 입력: [ERROR] 1,000원 단위로 입력해주세요. 출력 후 재입력 요청

[당첨 번호]
- 당첨 번호에 공백 입력: [ERROR] 빈 값은 입력할 수 없습니다. 출력 후, 재입력 요청
- 당첨 번호에 (실수, 음수, 0, 문자) 입력: [ERROR] 정수 이외의 값은 입력할 수 없습니다. 출력 후 재입력 요청
- 당첨 번호에 (6개 x) 입력: [ERROR] 6개의 정수를 입력하세요. 출력 후, 재입력 요청
- 당첨 번호에 (1~45 범위 밖 정수) 입력: [ERROR] 1~45 사이의 정수만 입력하세요. 출력 후, 재입력 요청
- 당첨 번호에 (중복숫자) 입력: [ERROR] 중복숫자는 입력할 수 없습니다. 출력 후, 재입력 요청

[보너스 번호]
- 보너스 번호에 공백 입력: [ERROR] 빈 값은 입력할 수 없습니다. 출력 후, 재입력 요청
- 보너스 번호에 (실수, 음수, 0, 문자) 입력: [ERROR] 정수 이외의 값은 입력할 수 없습니다. 출력 후, 재입력 요청
- 보너스 번호에 (1~45 범위 밖 정수) 입력: [ERROR] 1~45 사이의 정수만 입력하세요. 출력 후, 재입력 요청
- 보너스 번호에 (중복숫자) 입력: [ERROR] 당첨번호와 중복숫자는 입력할 수 없습니다. 출력 후, 재입력 요청

## Domain Rules
- 로또 번호 생성 규칙: 1~45 사이의 정수 6개를 중복없이 랜덤으로 생성
- 수익률: (당첨 금액 총액) / (구매 금액 총액)
